## LRU CACHE (Least-Recently Used Cache)

!image.png

출처: https://velog.io/@haero_kim/LRU-Cache-이해하기

LRU CACHE란 **CPU에서 디스크까지 걸리는 시간을 줄이기 위해 별도의 저장장소에 저장하는 캐시**를, LRU 형식 즉 **오래된 데이터는 삭제하는 식**으로 하여 구현하는 것이다.

### 구현 방식

Doubly Linked List로 구현하는 경우

→ HEAD쪽은 최근 사용된 데이터로, TAIL쪽은 오랫동안 사용되지 않은 데이터로 두어 새로운 데이터를 저장할 경우 HEAD에 삽입 후 연결

### 시간 복잡도

삽입 : 새로운 데이터를 HEAD에 추가 → O(1)

삭제 : TAIL(가장 오래 사용되지 않은 데이터)을 제거 → O(1)

조회 : 원하는 데이터를 찾기 위해 리스트를 순차 탐색 → O(N) 

캐시에 있는 데이터를 사용할 경우 : 조회한 뒤 HEAD로 이동
→ 전체 시간 복잡도 : O(N)

(단, HASH를 결합한 형태의 경우 조회는 O(1))

- 장점
    - 최근에 자주 사용하는 데이터를 빠르게 관리할 수 있다
    - 삽입 및 삭제가 O(1)로 빠르다
    - 구현이 비교적 직관적이다
- 단점
    - 특정 데이터를 찾기 위해 리스트를 순차 탐색해야 하므로 조회가 O(N)이다
    - Linked List를 사용하므로 포인터를 위한 추가 메모리가 필요하다

### 사용되는 곳?

- 운영체제의 페이지 교체(Page Replacement)
- DB, Web 등등 캐시
