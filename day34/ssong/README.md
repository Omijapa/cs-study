# Day 34 - 계수 정렬

계수 정렬은 원소끼리 직접 비교하지 않고, 각 값이 몇 번 등장했는지를 카운팅 하여 정렬하는 알고리즘이다.

예를 들어 다음 배열이 있다면

```java
[4, 2, 2, 8, 3, 3, 1]
```

등장 횟수를 카운팅하여 아래와 같이 정렬할 수 있다.

```java
1(1), 2(2), 3(2), 4(1), 5(0), 6(0), 7(0), 8(1), 9(0)

-> [1, 2, 2, 3, 3, 4, 8]
```

입력 받을 배열, 카운팅 횟수를 저장할 배열, 정렬된 배열 이렇게 총 3개의 배열 공간이 필요하다. 카운팅 횟수를 저장할 배열의 경우 입력 받은 배열의 원소 중 가장 큰 값을 기준으로 크기가 정해진다.

시간복잡도의 경우, 배열의 크기를 N, 원소의 최댓값을 K라고 하면 `O(N + K)`이다.

원본 배열 순회 O(N) + 카운팅 배열 순회 O(K)

공간복잡도의 경우 원소의 최댓값만큼의 크기가 필요하므로 O(K)이다. 그래서 계수 정렬의 경우 값 범위가 작고 밀집되어 있을 때 적합하다. 아니면 공간 낭비가 너무 심함
