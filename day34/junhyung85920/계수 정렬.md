**계수 정렬 (Counting Sort)**

입력 원소의 값이 정수나 정수로 표현될 수 있는 값을 정렬할 때 사용할 수 있는 데이터 분포 기반 정렬 알고리즘이다. 주어진 원소 중에서 자신보다 작거나 같은 값을 가지는 원소의 개수를 계산하여 정렬할 위치를 찾는다.

</aside>

---

# 구현

```python
def counting_sort(arr: list) -> list:
    maximum = max(arr)
    count_arr = [0] * (maximum + 1)
		
		# 최솟값 ~ 최댓값 범위에서 정수가 하나씩 있을 때, 각 정수들의 빈도를 계산
    for i in arr:
        count_arr[i] += 1
		
		# 각 정수의 빈도만큼 해당 정수를 추가한다 (extend)
    sorted_arr = []
    for i in range(len(count_arr)):
        sorted_arr.extend([i] * count_arr[i])

    return sorted_arr
```

---

# 시간 복잡도

- 입력 배열의 크기 n, 최댓값 - 최솟값 + 1 을 k 라고 할 때, O(n+k)의 시간 복잡도를 가진다.
