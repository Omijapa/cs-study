## Quick Sort (퀵 정렬)

(log2n에서 2는 밑)

탐색 범위가 정해진 배열에서, 하나의 원소를 피벗으로 선택한 후 피벗을 기준으로 작은 값과 큰 값을 분할(Divide)하고, 이를 재귀적으로 반복하여 정렬하는 방법

- 장점 :
    - 평균적으로 매우 빠른 정렬 알고리즘이며 추가 메모리가 거의 필요하지 않다 (In-place)
- 단점 :
    - 피벗 선택이 좋지 않으면 성능이 크게 저하되며, Stable하지 않다
    - 재귀 호출을 사용하므로 스택 메모리를 사용한다

### 정렬 과정

1. 배열 가운데서 하나의 원소를 고른다. 이렇게 고른 원소를 피벗 이라고 한다.
2. 피벗 앞에는 피벗보다 값이 작은 모든 원소들이 오고, 피벗 뒤에는 피벗보다 값이 큰 모든 원소들이 오도록 피벗을 기준으로 배열을 둘로 나눈다. 이렇게 배열을 둘로 나누는 것을 분할이라고 한다. 분할을 마친 뒤에 피벗은 더 이상 움직이지 않는다.
3. 분할된 두 개의 작은 배열에 대해 재귀적으로 이 과정을 반복한다.

---

```c
quickSort(left, right) {

    if (left >= right)
        return;

    pivot = arr[(left + right) / 2];

    i = left;
    j = right;

    while (i <= j) {
        while (arr[i] < pivot) i++;
        while (arr[j] > pivot) j--;

        if (i <= j) {
            swap(arr[i], arr[j]);
            i++;
            j--;
        }
    }

    quickSort(left, j);
    quickSort(i, right);
}
```

### 시간 복잡도

- 최선 : O(nlog2n)

→ 피벗이 항상 배열을 거의 절반씩 나누는 경우

- 평균 : O(nlog2n)

→ 피벗이 비교적 균등하게 분할되는 대부분의 경우

- 최악 : O(n^2)

→ 피벗이 항상 최솟값 또는 최댓값으로 선택되어 한쪽으로만 분할되는 경우 (정렬하고자 하는 차순의 정확히 역순으로 정렬되어 있는 경우)

ex) 이미 정렬되어 있거나 역순으로 정렬된 배열에서 첫 번째 또는 마지막 원소를 피벗으로 선택한 경우
