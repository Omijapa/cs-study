## IPC **(Inter Process Communication)**

IPC는 서로 다른 프로세스가 데이터를 주고받기 위한 통신 방법이며, 프로세스는 기본적으로 독립적인 메모리 공간을 사용하기 때문에 다른 프로세스의 메모리에 직접 접근할 수 없어 운영 체제가 제공하는 별도의 통신 방법을 사용.

프로세스 간 통신은 데이터를 전달하는 방식과 공유하는 방식으로 나눌 수 있으며, 대표적으로 Pipe, Message Queue, Shared Memory, Socket 등이 있음

### Pipe

P한 프로세스의 출력을 다른 프로세스의 입력으로 전달하는 통신 방식이며, 일반적으로 부모 프로세스와 자식 프로세스 사이에서 사용하고 기본적으로 한 방향으로 데이터를 전달

### Message Queue

프로세스가 전달할 데이터를 메시지 형태로 큐에 저장하고 다른 프로세스가 필요한 메시지를 가져가는 방식이며, 프로세스가 데이터를 전달하는 시점과 데이터를 처리하는 시점을 분리할 수 있음

### Shared Memory

여러 프로세스가 하나의 메모리 영역을 공유하여 데이터를 주고받는 IPC 방식이며, 프로세스 간 데이터를 복사할 필요가 없어 IPC 방식 중 빠른 편이지만 여러 프로세스가 동시에 접근할 수 있기 때문에 Race Condition을 방지하기 위한 동기화가 필요

### Socket

프로세스 간 네트워크를 통해 데이터를 주고받는 통신 방식이며, 서로 다른 컴퓨터에 존재하는 프로세스 사이에서도 통신할 수 있어 네트워크 프로그래밍에서 주로 사용
