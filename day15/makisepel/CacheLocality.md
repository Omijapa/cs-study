## Cache’s Locality (캐시의 지역성)

CPU가 최근에 접근한 데이터나 그 주변의 데이터를 다시 접근할 가능성이 높다는 특성으로, CPU와 메인 메모리 사이에 위치한 Cache는 이러한 지역성을 이용하여 자주 사용하는 데이터를 저장하고 메모리 접근 시간을 줄인다.

→ CPU가 메인 메모리에 접근하는 것보다 Cache에 접근하는 속도가 빠르기 때문에 Cache에 필요한 데이터가 존재하면 메인 메모리까지 접근하지 않아도 되어 프로그램의 실행 속도를 향상시킬 수 있음

### 시간적 지역성

최근에 접근한 데이터를 가까운 미래에 다시 접근할 가능성이 높은 특성이며, 반복문에서 같은 변수나 명령어를 반복해서 사용하는 경우가 대표적임

### 공간적 지역성

최근에 접근한 데이터와 가까운 주소의 데이터를 곧 접근할 가능성이 높은 특성이며, 배열의 원소를 순서대로 접근하거나 연속된 메모리 영역의 데이터를 사용하는 경우가 대표적임

### 순차적 지역성

순차적 지역성은 데이터나 명령어가 일정한 순서에 따라 연속적으로 접근되는 특성이며, 프로그램의 명령어가 순서대로 실행되거나 배열을 처음부터 순서대로 접근하는 경우 나타남
