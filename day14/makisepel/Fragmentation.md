## Fragmentation (단편화)

단편화는 메모리를 할당하고 해제하는 과정에서 메모리 공간이 작은 조각으로 나뉘어 발생하는 메모리 낭비 현상임

### 1. 외부 단편화

프로그램을 적재할 수 있을 만큼 큰 연속된 메모리 공간이 없어 발생하는 현상

전체 빈 공간의 크기는 충분하지만 여러 개의 작은 공간으로 나뉘어 있어 프로그램을 적재하지 못하는 경우가 해당함

### 2. 내부 단편화

프로그램에 할당된 메모리 공간이 실제 프로그램 크기보다 커서 할당된 공간 내부에 사용하지 못하는 공간이 남는 현상

예를 들어 10KB의 메모리 공간에 9KB의 프로그램을 할당하면 할당된 공간 내부에 남은 1KB가 내부 단편화가 됨

### 단편화와 메모리 할당 방식

연속 할당 방식에서는 하나의 프로세스를 연속된 메모리 공간에 적재하기 때문에 외부 단편화가 발생할 수 있으며, 고정 분할 방식에서는 내부 단편화도 발생할 수 있음

불연속 할당 방식에서는 하나의 프로세스를 여러 메모리 영역에 나누어 적재하여 외부 단편화를 줄일 수 있으며, 대표적으로 Paging과 Segmentation이 있음

- Paging : 고정된 크기로 나누기 때문에 내부 단편화가 발생할 수 있음
- Segmentation : 크기가 서로 다른 세그먼트로 나누기 때문에 외부 단편화가 발생할 수 있음

### Compaction

외부 단편화를 해결하기 위해 메모리에 흩어진 프로세스들을 한쪽으로 이동시켜 빈 공간을 하나의 큰 공간으로 만드는 방법임

메모리 데이터를 이동시키는 작업이 필요하기 때문에 추가적인 비용이 발생함
