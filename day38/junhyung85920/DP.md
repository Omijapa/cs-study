**DP (Dynamic Programming)**

하나의 문제를 여러 하위 문제로 나누어 풀고, 그것들을 결합해서 최종 목적에 도달하는 방식의 알고리즘 설계 기법

**문제 해결**

문제 내에서 조건에 따른 관계식 또는 점화식을 만들고 이를 Bottom up(반복문)이나 Top down(재귀)으로 구현 → 어려운 문제일수록 식이 여러 개 나와 분기문을 잘 작성해야함

</aside>

# 특징

## Memoization

- 중복되는 계산 결과를 저장한다.
    - 이전에 계산한 값이 필요할 때 가져와 사용함으로써 중복 계산을 방지하고 계산 속도를 향상시킨다.

## 장, 단점

- 중복 계산을 줄인다.
- 효율적인 시간 복잡도
- 메모리 사용량이 많다.

---

# 적용 조건

## 중복되는 부분 문제

- 동일한 작은 문제들이 반복하여 나타나는 경우

## 최적 부분 구조

- 부분 문제의 최적 결과 값을 사용해 전체 문제의 최적 해를 찾는 경우
