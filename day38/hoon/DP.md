# Day38 DP (Dynamic Programming; 동적 계획법)

## DP란
- 큰 문제를 **작은 문제들로 나누어 해결**한 뒤, 그 **결과를 저장해서 재사용**하는 알고리즘 기법
- **같은 계산을 반복하지 않는 것**이 핵심

### 피보나치 수열 예시
- 피보나치 수열 식: `F(n) = F(n-1) + F(n-2)`
- 단순 재귀로 `F(5)`를 구할 경우 F(3), F(2) 같은 값을 계속 다시 계산함
```text
F(5)
├─ F(4)
│  ├─ F(3)
│  └─ F(2)
└─ F(3)
   ├─ F(2)
   └─ F(1)
```

- DP에서는 한 번 계산한 값을 저장함
```text
dp[1] = 1
dp[2] = 1
dp[3] = dp[2] + dp[1]
dp[4] = dp[3] + dp[2]
dp[5] = dp[4] + dp[3]
```


## DP 사용 조건
- **중복되는 부분 문제(Overlapping Subproblems)**
    - 같은 작은 문제가 반복해서 등장함

- **최적 부분 구조(Optimal Substructure)**
    - 작은 문제의 답을 이용해 큰 문제의 답을 구할 수 있음


## DP의 두 가지 구현 방식

### 1. Top-Down (Memorization)
- 재귀적으로 문제를 풀면서 이미 계산한 값을 저장함
```python
dp = [-1] * 101

def fib(n):
    if n <= 1:
        return n

    if dp[n] != -1:
        return dp[n]

    dp[n] = fib(n - 1) + fib(n - 2)
    return dp[n]
```


### 2. Bottom-Up (Tabulation)
- 작은 문제부터 차례대로 계산함
```python
dp = [0] * 101

dp[1] = 1

for i in range(2, 101):
    dp[i] = dp[i - 1] + dp[i - 2]
```


## DP 문제에서 가장 중요한 것
- **dp[i]가 무엇을 의미하는지 정의하는 것**이 가장 중요

```text
(ex) LIS
dp[i] = i번째 원소를 마지막으로 가지는 가장 긴 증가 부분 수열의 길이
```

## 접근 방법
```text
1. dp 배열의 의미 정의
2. 초기값 설정
3. 점화식 찾기
4. 작은 문제부터 계산
```

## 참고

### Divide and Conquer과 비교
| 구분    | Divide and Conquer | Dynamic Programming     |
| ----- | ------------------ | ----------------------- |
| 핵심    | 문제를 독립적인 작은 문제로 분할 | 중복되는 작은 문제의 결과를 저장해 재사용 |
| 부분 문제 | 보통 서로 독립적          | 서로 중복되는 경우가 많음          |
| 결과 저장 | 보통 필요 없음           | Memoization/DP 배열에 저장   |
| 대표 예시 | 병합 정렬, 퀵 정렬        | 피보나치, 배낭 문제, LIS        |

- 분할 정복: 쪼개서 각각 해결한다.
- DP: 쪼갰더니 같은 문제가 또 나오므로, 답을 저장해 재사용한다.
