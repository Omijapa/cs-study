# Day 38 - DP

DP(Dynamic Programming)은 복잡한 문제를 작은 부분 문제로 나누어 해결하고, 그 결과를 저장해 중복 계산을 없애는 알고리즘

피보나치 수열이 대표적인 DP 문제이다

### DP 기본 구성

1. 상태 정의 : dp[i]가 의미하는게 무엇인가
2. 초기값: dp[0], dp[1], … 정의
3. 점화식 : dp[i]를 이전 상태들로 어떻게 계산하는가

### DP 구현 방법

#### Top-Down

재귀를 사용하면서 이미 계산한 값을 저장하는 “메모이제이션(Memoization)”

큰 문제 → 작은 문제 → 더 작은 문제 → 계산 → 결과 저장

#### Bottom-up

작은 문제 → 큰 문제 → 최종 답

코테에서는 bottom-up이 재귀문 없이 반복문으로 구현하기 편해서 자주 쓰임

### DP와 분할 정복의 차이

분할 정복은 부분 문제가 서로 겹치지 않는다. 즉 각 부분 문제들이 독립적으로 해결된다

DP는 부분 문제들이 서로 겹친다. 피보나치를 예로 들면 F(2), F(3) 이런 값들이 여러 부분 문제들에서 쓰인다

### 대표적인 문제 유형

1. 경우의 수 : 계단을 오르는 방법, 경로 개수, 동전으로 금액 만들기
2. 최댓값/최솟값 : 배낭 문제, 가장 큰 합, 최소 비용, LIS
3. 문자열 : LCS, 편집 거리, 문자열 변환
4. 2차원 DP : 격자 이동, 배낭 문제, LCS
