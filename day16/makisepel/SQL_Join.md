## SQL - Join

일반적으로 서로 관련된 컬럼을 기준으로 조건을 지정하여 두 개 이상의 테이블을 연결해서 서로 다른 테이블에 저장된 데이터를 함께 조회하는 방법

### INNER JOIN

두 테이블에서 JOIN 조건을 만족하는 데이터만 조회하는 방식

→ A ∩ B, 

두 테이블의 교집합에 해당하는 데이터만 결과에 포함됨

### LEFT OUTER JOIN

왼쪽 테이블의 모든 데이터와 JOIN 조건을 만족하는 오른쪽 테이블의 데이터를 조회하는 방식

→ A 전체 + A와 B의 일치하는 부분,

오른쪽 테이블에 일치하는 데이터가 없는 경우 해당 컬럼은 NULL로 표시됨

### RIGHT OUTER JOIN

오른쪽 테이블의 모든 데이터와 JOIN 조건을 만족하는 왼쪽 테이블의 데이터를 조회하는 방식

→ B 전체 + A와 B의 일치하는 부분,

왼쪽 테이블에 일치하는 데이터가 없는 경우 마찬가지로 해당 컬럼은 NULL로 표시

### FULL OUTER JOIN

두 테이블의 모든 데이터를 조회하는 방식임

→ A∪B, 

JOIN 조건을 만족하는 데이터는 하나로 연결하고, 일치하는 데이터가 없는 경우 NULL로 표시

### CROSS JOIN

두 테이블의 모든 행을 서로 조합하여 조회하는 방식

→ A의 행 수 × B의 행 수,

A 테이블의 모든 행과 B 테이블의 모든 행을 조합하므로 결과 행의 수는 두 테이블의 행 수를 곱한 값이 됨

### SELF JOIN

하나의 테이블을 자기 자신과 JOIN하는 방식

하나의 테이블에 서로 다른 별칭을 지정하여 마치 두 개의 테이블처럼 사용하며, 같은 테이블 내부의 행을 서로 비교하거나 연결할 때 사용
