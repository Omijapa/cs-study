## DFS (Depth-First Search, 깊이 우선 탐색)

DFS는 그래프(또는 트리)에서 **한 방향으로 가능한 만큼 깊이 탐색한 후, 더 이상 갈 곳이 없으면 이전 노드로 되돌아와 다른 경로를 탐색하는 알고리즘**이다. **재귀** 또는 스택을 이용하여 구현한다.

- 장점
    - 구현이 비교적 간단하고 메모리 사용량이 적다
    - 모든 경로를 탐색해야 하는 문제에 적합하다
- 단점
    - 최단 경로를 보장하지 않는다
    - 재귀 호출을 사용할 경우, 탐색 깊이가 깊으면 호출이 많아질 수 있다

### 동작 과정

1. 시작 노드를 방문한다
2. 방문한 노드와 연결된 노드 중 방문하지 않은 노드를 선택한다
3. 더 이상 방문할 노드가 없으면 이전 노드로 되돌아간다
4. 모든 노드를 방문할 때까지 반복한다

---

```c
void DFS(int v) {
    visited[v] = true;
    printf("%d ", v);
    
    for (int next : graph[v])
        if (!visited[next]) DFS(next);
}
```

### 시간 복잡도

최선 / 최악 / 평균 : O(V+E)

→ 이유 : 모든 정점과 간선을 최대 한 번씩 방문하기 때문

### 사용되는 곳?

- 그래프 및 트리 탐색
- 사이클 탐지
- 연결 요소(Connected Component) 탐색
