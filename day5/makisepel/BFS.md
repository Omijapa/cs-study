## BFS (Breadth-First Search)

- BFS(너비 우선 탐색)는 그래프(또는 트리)에서 **시작 노드와 가까운 노드부터 차례대로 탐색하는 알고리즘**이다. 주로 큐(Queue)를 이용하여 구현하며, **최단 경로 탐색**에 자주 사용된다.
- 장점
    - 최단 경로를 보장한다 (가중치가 없는 그래프)
    - 가까운 노드부터 탐색하므로 레벨 별 탐색에 적합하다
- 단점
    - 큐를 사용하므로 메모리 사용량이 많을 수 있다
    - 깊이가 깊고 노드 수가 많을 경우 비효율적일 수 있다

### 동작 과정

1. 시작 노드를 큐에 삽입하고 방문 처리한다
2. 큐에서 노드를 하나 꺼낸다
3. 방문하지 않은 인접 노드를 모두 큐에 삽입하고 방문 처리한다
4. 큐가 빌 때까지 반복한다

---

```c
void BFS(int start) {
    Queue q;
    enqueue(q, start);
    visited[start] = true;

    while (!isEmpty(q)) {
        int v = dequeue(q);
        printf("%d ", v);
        for (int next : graph[v]) {
            if (!visited[next]) {
                enqueue(q, next);
                visited[next] = true;
            }
        }
    }
}
```

### 시간 복잡도

최선 / 최악 / 평균 : O(V+E)

→ 이유 : 모든 정점과 간선을 최대 한 번씩 방문하기 때문

### 사용되는 곳?

- 그래프 및 트리 탐색
- 최단 경로 탐색 (가중치 없는 그래프)
- 네트워크 전파, 웹 크롤링
