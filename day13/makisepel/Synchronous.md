## 동기와 비동기

### 동기(Synchronous)

요청한 작업의 결과가 반환될 때까지 기다린 후 다음 작업을 수행하는 방식

- 요청과 결과가 순차적으로 처리됨
- 작업이 완료될 때까지 대기하므로 **Blocking** 방식으로 동작할 수 있음
- 구현이 단순하고 흐름을 이해하기 쉬움
- 작업 시간이 길 경우 결과를 기다리는 동안 다른 작업을 수행하지 못함

### 비동기(Asynchronous)

작업을 요청한 후 결과를 기다리지 않고 다음 작업을 수행하는 방식

- 요청한 작업과 다음 작업을 동시에 진행할 수 있음
- 작업이 완료되면 이벤트, 콜백 등의 방식으로 결과를 전달받을 수 있음
- 작업 결과를 기다리지 않기 때문에 **Non-blocking** 방식으로 동작할 수 있음
- 여러 작업을 효율적으로 처리할 수 있지만 구현이 상대적으로 복잡함
