# 운영 체제 및 컴퓨터 시스템의 동작 원리

## 운영 체제 (Operating System, OS)

운영 체제는 사용자와 컴퓨터 하드웨어 사이에서 **중개자 역할을 수행하는 시스템 소프트웨어**이다. 사용자가 실행하는 다양한 응용 프로그램이 하드웨어를 직접 제어하지 않고도 실행될 수 있도록 지원하며, CPU, 메모리, 저장장치, 입출력 장치 등의 컴퓨터 자원을 효율적으로 관리한다.

### 운영 체제의 주요 역할

#### 1. 프로세스 관리

- 실행 중인 프로그램(프로세스)을 생성, 실행, 종료함
- CPU를 여러 프로세스에 효율적으로 분배함
- CPU 스케줄링 알고리즘을 이용하여 여러 프로세스가 동시에 실행되는 것처럼 관리함

#### 2. 메모리 관리

- 프로그램 실행에 필요한 메모리 공간을 할당함
- 사용이 끝난 메모리를 회수하여 다른 프로그램이 사용할 수 있도록 관리함
- 가상 메모리(Virtual Memory)를 이용하여 실제 메모리보다 큰 메모리를 사용하는 것처럼 지원함

#### 3. 파일 시스템 관리

- 파일 및 디렉터리의 생성, 삭제, 수정, 검색을 관리함
- 접근 권한 및 저장 공간을 관리하여 데이터를 안전하게 저장하도록 지원함

#### 4. 입출력(I/O) 장치 관리

- 키보드, 마우스, 모니터, SSD 등의 입출력 장치를 관리함
- 응용 프로그램이 하드웨어를 직접 제어하지 않고 운영 체제를 통해 장치를 사용할 수 있도록 지원함

#### 5. 보안 및 자원 보호

- 사용자별 접근 권한을 관리함
- 비정상적인 접근 및 악성 프로그램으로부터 시스템 자원을 보호함

# 컴퓨터 시스템의 동작 원리

컴퓨터 시스템은 **하드웨어(Hardware)**와 **소프트웨어(Software)**가 함께 동작하여 사용자의 명령을 처리한다. 사용자가 프로그램을 실행하면 운영 체제가 프로그램을 메모리에 적재하고, CPU가 명령어를 처리하여 원하는 결과를 생성한다.

### 컴퓨터 시스템의 구성

- CPU(Central Processing Unit)
- 메모리(Main Memory, RAM)
- 저장장치(SSD, HDD)
- 입출력 장치(I/O Device)
- 시스템 버스(System Bus)

각 장치는 운영 체제의 관리 아래 데이터를 주고받으며 프로그램을 실행

### 프로그램 실행 과정

#### 1. 프로그램 실행 요청

- 사용자가 프로그램을 실행함
- 운영 체제가 저장장치에 있는 실행 파일을 메모리(RAM)로 적재함

#### 2. 메모리 적재

- 프로그램 실행에 필요한 메모리 공간을 할당함
- 코드(Code), 데이터(Data), 스택(Stack), 힙(Heap) 영역을 초기화함

#### 3. CPU의 명령어 처리

CPU는 **Instruction Cycle(명령어 사이클)**을 반복 수행

- **Fetch(인출)** : 메모리에서 명령어를 가져옴
- **Decode(해독)** : 가져온 명령어를 해석함
- **Execute(실행)** : 명령어를 수행함
- **Store(저장)** : 실행 결과를 메모리 또는 레지스터에 저장함

위 과정을 매우 빠르게 반복하여 프로그램을 실행

### 메모리 계층 구조

컴퓨터는 성능 향상을 위해 메모리를 계층 구조로 관리

```
CPU Register → Cache Memory → Main Memory(RAM) → SSD / HDD
```

- 왼편 << 속도가 빠르고 용량이 작으며 가격이 비쌈
- 오른편 <<속도는 느리지만 용량이 크고 가격이 저렴함
- CPU는 레지스터부터 화살표 순으로 데이터를 탐색

### 캐시(Cache)

CPU와 RAM 사이에 위치한 고속 메모리로 자주 사용하는 데이터를 저장하여 RAM 접근 횟수를 줄이고 프로그램 실행 속도를 향상시킴. 최근에 사용한 데이터를 다시 사용할 가능성이 높다는 **지역성(Locality)** 원리를 이용하여 동작함

### 인터럽트(Interrupt)

프로그램 실행 도중 특정 이벤트가 발생했을 때 CPU에 현재 작업을 잠시 중단하고 해당 작업을 먼저 처리하도록 요청하는 신호

인터럽트가 발생하면 CPU는 현재 작업을 잠시 중단하고 인터럽트 처리 루틴을 수행한 후 원래 작업으로 복귀함

ex) 키보드 입력, 마우스 클릭, 타이머 종료, 디스크 입출력 완료

### 시스템 버스(System Bus)

컴퓨터 내부 장치 간 데이터를 전달하는 통로 역할, CPU는 시스템 버스를 통해 메모리와 입출력 장치에 접근한다.

- **데이터 버스(Data Bus)** : 데이터 전달
- **주소 버스(Address Bus)** : 메모리 주소 전달
- **제어 버스(Control Bus)** : 제어 신호 전달

### 커널(Kernel)

커널은 운영 체제의 핵심 부분으로, CPU, 메모리, 저장장치 및 입출력 장치와 같은 **하드웨어를 직접 관리하는 프로그램**이며 응용 프로그램은 하드웨어에 직접 접근하지 않고 반드시 커널을 통해 필요한 기능을 요청

- 프로세스 및 스레드 관리
- CPU 스케줄링
- 메모리 관리
- 파일 시스템 관리
- 입출력 장치 관리
- 시스템 보안 및 권한 관리

### 사용자 모드(User Mode)와 커널 모드(Kernel Mode)

컴퓨터 시스템은 시스템의 안정성과 보안을 위해 CPU의 실행 권한을 **사용자 모드**와 **커널 모드**로 구분하여 시스템 안정성과 보안을 유지

- **사용자 모드(User Mode)** : 응용 프로그램이 실행되는 영역이며, 하드웨어 및 시스템 자원에 직접 접근할 수 없음
- **커널 모드(Kernel Mode)** : 운영 체제가 실행되는 영역이며, 모든 시스템 자원과 CPU 명령어에 접근 가능함

### 시스템 콜(System Call)

응용 프로그램이 운영 체제의 기능을 요청하기 위한 인터페이스

- `open()` : 파일 열기
- `read()` : 파일 읽기
- `write()` : 파일 쓰기
- `close()` : 파일 닫기
- `fork()` : 새로운 프로세스 생성

++ 동작 순서 : 응용 프로그램 → 시스템 콜 → 운영 체제(커널) → 하드웨어

### 입출력(I/O)의 동작 과정

1. 응용 프로그램이 시스템 콜을 통해 입출력을 요청함
2. 운영 체제가 해당 장치에 작업을 요청함
3. 장치가 작업을 수행하는 동안 CPU는 다른 작업을 수행함
4. 작업 완료 후 인터럽트를 발생시켜 CPU에 완료를 알림
5. 운영 체제가 인터럽트를 처리한 후 결과를 응용 프로그램에 전달함

CPU는 입출력 작업을 기다리지 않고 다른 작업을 수행하여 시스템 효율을 높임
