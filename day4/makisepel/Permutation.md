## 순열 (Permutation Algorithm)

순열이란? 확통에서 나온 nPr, 즉 n개 중 r개를 뽑아 순서를 고려해서 나열하는 것을 말한다. 즉 순열 알고리즘이란 **주어진 배열에서 원소들의 순서를 바꾸어서 만들 수 있는 모든 경우의 수를 생성하는 알고리즘**을 말한다.

### 동작 과정

1. 현재 위치에 들어갈 원소를 하나 선택한다
2. 선택한 원소를 현재 위치와 Swap한 후 다음 위치에 대해 재귀적으로 순열을 생성한다
3. 재귀가 종료되면 교환한 원소를 다시 원래 위치로 **Backtracking(복구)**하여 다음 경우를 탐색한다

---

```c
perm(depth) {
    if (depth == n) {
        print(arr);
        return;
    }

    for (i = depth; i < n; i++) {
        swap(arr[depth], arr[i]);
        perm(depth + 1);
        swap(arr[depth], arr[i]); // 재귀 이후 Backtracking
    }
}

```

→ 초기 호출은 perm(0)을 통해 호출, 이후 재귀를 통해 자동 탐색. arr은 배열 / n은 배열의 길이

### 시간 복잡도

최선 / 최악 / 평균 : O(n!) 

→ n개의 원소로 만들 수 있는 모든 경우의 수를 생성해야 하므로

### 사용되는 곳?

- 암호 및 비밀번호 조합 생성
- Brute Force (모든 경우의 수 탐색)
