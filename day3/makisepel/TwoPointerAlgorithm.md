## Two-Pointer Algorithm (투포인터 알고리즘)

일반적으로 **정렬된 배열 (또는 리스트)**에서, **2개의 Pointer**를 사용하여 **“특정 조건을 만족하는 부분(또는 구간)”**을 탐색하기 위한 알고리즘

- 장점
    - 시간 복잡도가 낮고 구현이 비교적 간단하다 (포인터 2개만 옮길 수 있으면 된다.)
- 단점
    - 정렬된 배열을 전제로 한다
    - 문제의 조건에 따라 포인터 이동 규칙을 직접 설계해야 한다
    - 모든 탐색 문제에 적용할 수 있는 것은 아니다 (설명에도 있듯 특정 조건을 만족하는 **부분**을 탐색하기 위한 용도이며, 하나의 원소를 찾는 데에는 적합하지 않음)

### 동작 과정

1. 두 개의 포인터를 적절한 위치에 배치한다
2. 현재 두 포인터(또는 구간)가 조건을 만족하는지 확인한다
3. 조건에 따라 왼쪽 또는 오른쪽 포인터를 이동시킨다
4. 모든 탐색이 끝날 때까지 2, 3번을 반복한다

---

```c
left = 0;
right = n - 1;

while (left < right) {

    sum = arr[left] + arr[right];

    if (sum == target) break; // 해당 조건문 안에 구현하고자 하는 조건을 넣으면 되겠다
    else if (sum < target) left++;
    else right--;
}
```

### 시간 복잡도

최선 / 최악 / 평균 : O(n)

→ 포인터 2개를 선형적으로 움직이는 알고리즘이기 때문에 (반복문 1개)

### 사용되는 곳?

문자열 탐색 (비교 등 포함), 배열에서 원소의 합 찾기, 등등
