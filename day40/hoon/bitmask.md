# Day40 Bitmask

## 1. 비트마스크란
- **정수의 각 비트 (0,1)를 이용해 여러 개의 상태를 표현하는 방법**
- 각 비트를 하나의 원소나 상태의 선택 여부로 사용
- `0`: 선택되지 않음
- `1`: 선택됨

```text
  A B C D
  0 1 0 1
```
- 위 상태는 B,D가 선택된 상태임을 의미
- 여러 개의 `True / False`값을 정수 하나로 표현할 수 있음

## 2. 비트마스크 활용
- 부분집합 표현
- 방문 여부 저장
- 여러 상태의 선택 여부 저장
- 비트마스크 DP에서 상태 표현

```text
예: 원소가 {A, B, C}라면

000 → {}
001 → {A}
010 → {B}
011 → {A, B}
100 → {C}
101 → {A, C}
110 → {B, C}
111 → {A, B, C}
```

- 원소가 `N`개라면 가능한 상태는 `2^N`개


## 3. 주요 비트 연산

### 특정 원소 추가
- OR 연산 `|` 사용

```text
mask |= (1 << i)
```

### 특정 원소 포함 여부 확인
- AND 연산 `&` 사용

```python
if mask & (1 << i):
    
    print("선택됨")
```

### 특정 원소 제거
- AND와 NOT 연산 사용

```text
mask &= ~(1 << i)
```

### 특정 원소 상태 반전
- XOR 연산 `^` 사용
- 선택되어 있으면 제거, 선택되어 있지 않으면 추가

```text
mask ^= (1 << i)
```

## 4. 부분집합 탐색

```python
n = 3

for mask in range(1 << n):
    print(mask)

```
```text
결과

0
1
2
3
4
5
6
7
```
| mask |  이진수  | 부분집합        |
| ---: | :---: | ----------- |
|    0 | `000` | `{}`        |
|    1 | `001` | `{A}`       |
|    2 | `010` | `{B}`       |
|    3 | `011` | `{A, B}`    |
|    4 | `100` | `{C}`       |
|    5 | `101` | `{A, C}`    |
|    6 | `110` | `{B, C}`    |
|    7 | `111` | `{A, B, C}` |

- `1 << n`은 `2^n`을 의미
- `0`부터 `2^n - 1`까지 탐색하면 모든 부분집합을 표현할 수 있음

> 비트마스크는 각 비트를 하나의 스위치처럼 사용하여 여러 상태를 하나의 정수로 표현하는 기법이다.
