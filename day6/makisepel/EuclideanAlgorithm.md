## 최대 공약수 / 최소 공배수 / 유클리드 호제법 (GCD / LCM / Euclidean Algorithm)

- **최대 공약수(GCD, Greatest Common Divisor)** : 두 수를 모두 나눌 수 있는 가장 큰 수
- **최소 공배수(LCM, Least Common Multiple)** : 두 수의 공통 배수 중 가장 작은 수
- **유클리드 호제법(Euclidean Algorithm)** : 두 수의 나머지를 이용하여 최대 공약수를 구하는 알고리즘, 즉 두 수가 서로 상대방 수를 나누어서 원하는 수를 얻는 방법.

- 장점
    - 구현하기 쉽고 결과를 빠르게 구할 수 있다
- 단점
    - 최대 공약수와 최소 공배수 계산에만 사용할 수 있다
    - 여러 수를 계산하려면 반복적으로 수행해야 한다

### 동작 과정

1. 두 수를 준비한다
2. 큰 수를 작은 수로 나눈 나머지를 구한다
3. 큰 수를 작은 수로, 작은 수를 나머지로 갱신한다
4. 나머지가 0이 될 때까지 반복한다
5. 마지막으로 0이 아닌 수가 최대 공약수(GCD)가 된다

---

```c
int GCD(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    
    return a;
}
```

### 시간 복잡도

최선 : O(1)

→ 나머지가 0인 경우 (즉, 두 수 중 하나가 다른 수의 배수인 경우)

평균 / 최악 : O(log n)

→ 이유 : 나머지를 반복적으로 계산할 때마다 수의 크기가 빠르게 감소하기 때문

### 사용되는 곳?

- 암호학 및 수학 알고리즘
- 정수론(Number Theory) 문제
