## Deadlock (교착 상태)

교착 상태는 **여러 프로세스가 서로 상대방이 가지고 있는 자원을 기다리면서 계속 대기하는 상태**이다. 한정된 자원을 여러 프로세스가 사용하는 상황에서 발생하며, 서로 자원을 점유하고 놓지 않아 다음 작업을 수행하지 못하게 됨

### 발생 예시

프로세스 P1과 P2가 자원 R1과 R2를 모두 필요로 한다고 가정

t1 : P1 → R1 할당 / P2 → R2 할당

t2 : P1 → R2 요청 → 대기 / P2 → R1 요청 → 대기

P1은 P2가 가진 R2를 기다리고, P2는 P1이 가진 R1을 기다리게 되며 서로 상대방의 자원을 기다리면서 자원을 반납하지 않기 때문에 두 프로세스 모두 계속 대기하게 됨

### 주로 발생하는 경우

- 여러 프로세스가 한정된 자원을 사용하기 위해 경쟁하는 경우
- 하나의 프로세스가 자원을 점유한 상태에서 다른 자원을 추가로 요청하는 경우
- 요청한 자원을 다른 프로세스가 사용하고 있어 대기하는 경우

## 발생 조건

#### 1. 상호 배제(Mutual Exclusion)

자원을 한 번에 하나의 프로세스만 사용할 수 있는 상태

→ 다른 프로세스는 기존 프로세스가 자원을 반납할 때까지 기다려야 함

#### 2. 점유 대기(Hold and Wait)

프로세스가 하나 이상의 자원을 점유한 상태에서 다른 자원을 추가로 얻기 위해 대기하는 상태

#### 3. 비선점(No Preemption)

다른 프로세스가 사용 중인 자원을 강제로 빼앗을 수 없는 상태

→ 자원을 사용 중인 프로세스가 작업을 끝내고 직접 반납해야 함

#### 4. 순환 대기(Circular Wait)

프로세스들이 서로가 점유하고 있는 자원을 순환 형태로 기다리는 상태

### 처리 방법

#### 1. 교착 상태 예방(Prevention)

교착 상태 발생 조건 4가지 중 하나 이상을 제거하여 교착 상태가 발생하지 않도록 하는 방법

1. 상호 배제 부정
    - 여러 프로세스가 하나의 자원을 동시에 사용할 수 있도록 함
    - 공유가 가능한 자원에 적용 가능함
2. 점유 대기 부정
    - 프로세스가 실행되기 전에 필요한 모든 자원을 한 번에 할당함
    - 필요한 자원을 모두 얻지 못하면 자원을 점유하지 않도록 함
3. 비선점 부정
    - 다른 프로세스가 점유하고 있는 자원을 강제로 회수할 수 있도록 함
    - 추가 자원이 필요한 경우 현재 가지고 있는 자원을 반납하고 다시 대기하도록 함
4. 순환 대기 부정
    - 자원에 고유한 순서를 부여함
    - 정해진 순서대로만 자원을 요청하도록 함
    - 자원의 요청 순서를 제한하여 순환 대기를 방지함

#### 2. 교착 상태 회피(Avoidance)

프로세스가 자원을 요청할 때 자원을 할당해도 교착 상태가 발생하지 않는지 확인한 후 자원을 할당하는 방법으로, ****대표적인 방법으로 은행원 알고리즘(Banker's Algorithm)이 있음

- 은행원 알고리즘은 다익스트라가 제안한 방법으로, 은행이 고객에게 자금을 빌려줄 때 모든 고객의 요구를 충족하면서도 문제가 발생하지 않도록 자원을 관리하는 방식에서 유래

자원을 할당한 후 시스템이 안전 상태를 유지할 수 있는지 확인함

- 안전 상태 : 자원 할당
- 불안전 상태 : 자원 할당을 보류하고 대기

#### 3. 교착 상태 탐지(Detection)

교착 상태가 발생한 이후 교착 상태가 발생했는지 확인하는 방법 (대표적으로 자원 할당 그래프를 이용)

- 프로세스 → 자원 : 프로세스가 해당 자원을 요청하고 대기 중
- 자원 → 프로세스 : 해당 자원이 프로세스에 할당되어 있음
- 그래프에 순환(Cycle)이 존재하는지 확인함

⇒  탐지 알고리즘을 자주 실행할 경우 추가적인 오버헤드가 발생

#### 4. 교착 상태 회복(Recovery)

교착 상태가 발생한 이후 프로세스를 종료하거나 자원을 회수하여 교착 상태를 해결하는 방법

- 프로세스 종료
    - 교착 상태에 있는 모든 프로세스를 종료함
    - 교착 상태가 해결될 때까지 하나씩 프로세스를 종료
- 자원 선점
    - 교착 상태에 있는 프로세스가 가지고 있는 자원을 강제로 회수함
    - 회수한 자원을 다른 프로세스에 할당함
    - 필요한 경우 해당 프로세스를 일시 정지
